# Little Bloom 🌸

A free, open-source pregnancy companion PWA — month-by-month and week-by-week guide with baby brain-development milestones, simple bonding activities, breathing exercises, kick counter, Indian diet guide, checklists and warning signs. English, Hindi and Telugu.

- Live: https://yelchurisaimanoj.github.io/little-bloom/
- Static site, no backend. All personal data (due date, kick counts, checklists) stays in the browser's local storage on the user's device.
- Content follows public guidance from NHS, WHO, CDC and pregnancybirthbaby.org.au. It is general information, not medical advice.
- Sources: see the About page in the app.

## Tech
Plain HTML/CSS/JS, service worker for offline use, installable manifest. No build step.
